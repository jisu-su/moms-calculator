# `hooks/` — 커스텀 훅 디렉토리

화면(`app/`)과 데이터 레이어(`db/`) 사이의 중간 계층.  
DB 호출, 상태 관리, 계산 로직을 React 훅으로 캡슐화해 화면에서 가져다 쓴다.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `useEmployees.ts` | 알바생 목록 조회 + 추가/수정/삭제. loading, error 상태 포함 |
| `useWorkLogs.ts` | 특정 알바생의 근무 기록 조회 + 추가/수정/삭제 |
| `usePayCalc.ts` | 현재 정산 기간을 계산하고 시급 × 총 근무 시간으로 월급을 산출 |

## 규칙

- 훅은 반드시 `use`로 시작하는 이름을 가진다.
- 화면은 `db/`를 직접 import하지 않고, 이 폴더의 훅을 통해서만 데이터에 접근한다.
- 각 훅은 `loading`, `error`, `refetch` 를 기본으로 반환한다.
- 계산의 핵심 로직은 `utils/`에 두고, 훅은 그것을 호출하는 역할만 한다.
