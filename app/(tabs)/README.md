# `app/(tabs)/` — 하단 탭 화면 그룹

하단 네비게이션 바로 이동하는 주요 화면 2개를 묶은 그룹.  
괄호 `(tabs)`는 expo-router의 그룹 표기로, URL 경로에는 포함되지 않는다.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `_layout.tsx` | 하단 탭 바 구성 — 탭 2개(알바생 조회, 달력 조회), 아이콘 + 텍스트 |
| `home.tsx` | 홈 화면 — 전체 알바생 카드 목록 (월급날 빠른 순 정렬), 근무 입력 FAB 버튼 |
| `calendar.tsx` | 달력 조회 화면 — 월별 달력, 날짜 선택 시 해당일 출근 알바생 목록 표시 |

## 탭 구성

```
[알바생 조회 👥]  [달력 조회 📅]
     home              calendar
```

## 규칙

- 탭은 2~3개 이하를 유지한다 (PRD 5-3 하단 네비게이션 기준).
- 활성 탭 색상: `#7C5CBF`, 비활성 탭 색상: `#9E9E9E`.
