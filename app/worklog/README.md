# `app/worklog/` — 근무 기록 관련 화면

알바생의 근무 시간을 입력하는 화면.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `new.tsx` | 근무 시간 입력 화면 — 알바생 선택, 날짜 선택(기본값: 전날), 출퇴근 시간 입력(ClockPicker) |

## 주요 흐름

```
홈(home.tsx)
  └── 근무 시간 입력 버튼(FAB) → new.tsx → 저장 → 홈
```

## 참고

- 날짜 기본값은 **전날**로 설정된다 (마감 후 다음 날 입력하는 패턴을 고려).
- 근무 시간(`hours`)은 출퇴근 시간으로 자동 계산되어 `work_logs` 테이블에 저장된다.
