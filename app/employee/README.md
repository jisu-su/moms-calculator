# `app/employee/` — 알바생 관련 화면

알바생 추가 및 상세 조회/수정/삭제 화면.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `new.tsx` | 알바생 추가 화면 — 이름, 일 시작한 날, 시급(고정 11,000원), 첫 월급날, 계좌번호 앞 5자리 입력 |
| `[id].tsx` | 알바생 상세 화면 — 이름, 계좌번호, 미니 달력(근무일/월급날 표시), 월급 계산 결과, 수정/삭제 |

## 주요 흐름

```
홈(home.tsx)
  ├── + 버튼 → new.tsx → 저장 → 홈
  └── 카드 선택 → [id].tsx → 수정/삭제 → 홈
```
