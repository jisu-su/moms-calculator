# `components/` — 재사용 UI 컴포넌트 디렉토리

화면(`app/`)에서 가져다 쓰는 재사용 가능한 UI 컴포넌트 모음.  
화면 전용 로직은 포함하지 않고, 표시(UI)와 이벤트 전달만 담당한다.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `EmployeeCard.tsx` | 홈 목록에서 알바생 1명을 카드 형태로 표시 (이름, 월급날, 오늘까지의 월급) |
| `EmployeeSearch.tsx` | 근무 입력 화면에서 알바생을 선택하는 칩 UI |
| `ClockPicker.tsx` | 출근/퇴근 시간을 입력하는 시계 UI (아날로그 + 디지털) |
| `MiniCalendar.tsx` | 알바생 상세 화면의 미니 달력 (근무일 점 표시, 월급날 동그라미) |
| `CalendarDotView.tsx` | 달력 조회 탭의 월별 달력 (날짜별 출근 알바생 수만큼 점 표시) |

## 하위 디렉토리

- **`ui/`** — 앱 전역에서 쓰이는 기초 UI 컴포넌트 (버튼, 입력 필드, 카드, 모달)

## 규칙

- 컴포넌트는 데이터를 직접 가져오지 않는다. 필요한 데이터는 **props**로 전달받는다.
- 비즈니스 로직(계산, DB 호출)은 `hooks/` 또는 `utils/`에서 처리한다.
- 한 컴포넌트는 한 가지 역할만 담당한다 (단일 책임 원칙).
