# `components/ui/` — 기초 UI 컴포넌트 디렉토리

앱 전역에서 공통으로 사용되는 가장 기본 단위의 UI 컴포넌트.  
디자인 시스템(색상, 타이포그래피, 간격)을 직접 적용해 일관된 시각을 유지한다.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `Button.tsx` | 공통 버튼 — 기본/비활성/로딩 상태, primary/secondary 변형 지원 |
| `Input.tsx` | 공통 입력 필드 — 기본/포커스/완료/오류 상태, 라벨 + 오류 메시지 포함 |
| `Card.tsx` | 공통 카드 — 흰 배경, 둥근 모서리, 선택 시 왼쪽 보더 강조 |
| `Modal.tsx` | 공통 모달 — 반투명 딤 배경, 확인/취소 2버튼 구성 |

## 규칙

- `constants/colors.ts`, `constants/typography.ts`의 토큰만 사용한다. 하드코딩 금지.
- 최소 터치 영역 **48×48dp** 이상 보장 (PRD 접근성 기준).
- 최소 글자 크기 **18sp** 이상 (PRD 접근성 기준).
- 비즈니스 로직을 포함하지 않는다.
