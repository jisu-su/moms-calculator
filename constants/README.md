# `constants/` — 전역 상수 디렉토리

앱 전체에서 공유하는 디자인 토큰과 설정 값.  
색상, 폰트 크기, 기본값을 한 곳에서 관리해 일관성을 보장한다.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `colors.ts` | 앱 전체 색상 팔레트 (primary, background, text, error 등) |
| `typography.ts` | 폰트 패밀리와 크기 체계 (body 18sp, subheading 20sp, amount 24sp 등) |
| `defaults.ts` | 앱 기본값 (기본 시급 11,000원, 알림 시간대, 스플래시 지속 시간 등) |

## 규칙

- 색상이나 폰트 크기를 컴포넌트 파일에 직접 하드코딩하지 않는다. 반드시 이 폴더에서 import한다.
- 내보내는 값은 모두 `as const`로 선언해 타입 안전성을 보장한다.
- PRD 5-2 시각 시스템을 기준으로 하며, 변경 시 이 파일만 수정하면 전체 앱에 반영된다.
