# `utils/` — 유틸리티 함수 디렉토리

React나 React Native에 의존하지 않는 순수 함수(Pure Function) 모음.  
계산 로직과 날짜 처리를 담당하며, 훅이나 컴포넌트 어디서든 자유롭게 import해 사용한다.

---

## 파일 목록

| 파일 | 역할 |
|---|---|
| `payCalc.ts` | 시급 × 근무 시간 계산, HH:MM 파싱, 원화 포맷 변환 |
| `dateUtils.ts` | 날짜 포맷 변환, D-day 계산, 정산 기간 계산, 전날 기본값, 월별 날짜 배열 생성 |

## 핵심 로직: 정산 기간 계산 (`dateUtils.ts`)

PRD 6-3 기준 — 정산 주기는 월급날이 아니라 **일 시작한 날(startDate)** 기준.

```
예시: startDate = 2025-03-02
  → 3월 정산 기간: 2025-03-02 ~ 2025-04-01
  → 4월 정산 기간: 2025-04-02 ~ 2025-05-01
```

## 규칙

- 이 폴더의 함수는 React 훅(`useState`, `useEffect` 등)을 사용하지 않는다.
- 부수 효과(side effect) 없이 입력값 → 출력값만 반환하는 순수 함수로 작성한다.
- 단위 테스트(`jest`)의 주요 대상이다. 특히 `payCalc.ts`의 계산 오류는 치명적이므로 반드시 테스트한다.
